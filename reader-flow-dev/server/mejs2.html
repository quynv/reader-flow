Multiple Captions

Video with multiple captions

Code

<video id="player1" width="640" height="360" style="max-width:100%;" poster="/img/poster.png" preload="none" controls playsinline webkit-playsinline>
  <source src="//127.0.0.1:8765/media/clip.mp4?raw=true" type="video/mp4">
  <track srclang="en" kind="subtitles" src="/media/english.vtt" default>
</video>

Quality Chooser Plugin

Selection of multiple sources.

Code

<video id="player2" width="640" height="360" style="max-width:100%;" preload="none" controls playsinline webkit-playsinline>
  <source src="/media/clip.mp4" type="video/mp4" data-quality="HD" title="HD">
  <source src="/media/clip_sd.mp4" type="video/mp4" data-quality="SD" title="SD">
</video>
